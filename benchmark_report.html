🎯 Recommendations

Use opticode if:

  • ✅ You value developer time over marginal token costs
  • ✅ You want consistent, predictable AI outputs
  • ✅ You're frustrated with clarification round-trips
  • ✅ You work on codebases where context matters
  • ✅ You want enforced constraints (DONT change unrelated files)

Don't use opticode if:

  • ❌ Your only goal is minimizing token costs
  • ❌ All your requests are extremely specific one-liners
  • ❌ You prefer conversational interaction with AI

🔧 Technical Details

Processing Speed

  • Intent analysis (rules): ~0.05ms
  • Intent analysis (model): ~50-200ms
  • Prompt optimization: ~0.1ms
  • File snippet extraction: ~0.5ms

Model Information

  • Default: Qwen2-0.5B-Instruct (Q4_K_M quantized)
  • Size: ~400MB
  • RAM when loaded: ~600MB
  • Inference: llama.cpp (C++ backend)
  • Fallback: Rule-based heuristics (no model needed)
Methodology Notes:
  • Benchmarks run on 20 test scenarios across 6 categories
  • Token estimates: 1 token ≈ 4 characters for English text
  • Time estimates assume 2s API latency per call
  • First-try success based on benchmark observation
  • Pricing: OpenAI GPT-4 as of January 2025
  • Developer rate: $100/hour (adjust for your region)
